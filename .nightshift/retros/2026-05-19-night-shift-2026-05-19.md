## SYSTEM gaps surfaced

1. **Worker-pinning is not enforced by the dispatch prompt.** The Agent tool's `isolation: "worktree"` flag is not 100% reliable — workers can land in the shared checkout and never re-route to their worktree. Static guard rails inside the prompt are necessary. Branch protection on `main` is the load-bearing backstop.
2. **Lifecycle-label hygiene is implicit.** Workers add `in-progress` explicitly on Step 2 but rely on the GH autoclose to remove it implicitly. The autoclose strips the issue's open state, not its labels. Closed issues end up with stale `in-progress`.
3. **Skill spec / implementation drift.** `/ro:completion-report` documents a scripts/ directory that doesn't ship with the plugin. The orchestrator (this main loop) had to inline the implementation. Worth a SYSTEM follow-up to fix the drift, but doesn't block work — the orchestrator route is viable.
