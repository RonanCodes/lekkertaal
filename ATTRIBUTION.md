# Data sources

Lekkertaal uses content from the following third-party sources. Each source
requires attribution under its licence terms. Attribution is also surfaced
in-app via the per-word info popover on flashcard and match-pairs drills.

## Wiktionary

- **Source:** [en.wiktionary.org](https://en.wiktionary.org/)
- **Licence:** [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- **Used for:** IPA pronunciation, grammatical gender, word type
- **Per-word link:** `https://en.wiktionary.org/wiki/<word>`

## Wikimedia Commons

- **Source:** [commons.wikimedia.org](https://commons.wikimedia.org/)
- **Licence:** Varies per file; Dutch pronunciation recordings are primarily
  [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) contributed
  by native speakers via the Wiktionary project.
- **Used for:** Native-speaker audio recordings (`.ogg` files, transcoded to MP3)
- **Per-word link:** `https://commons.wikimedia.org/wiki/File:Nl-<word>.ogg`

## Tatoeba

- **Source:** [tatoeba.org](https://tatoeba.org/)
- **Licence:** [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/)
- **Used for:** Dutch/English example sentence pairs
- **Per-sentence link:** `https://tatoeba.org/en/sentences/show/<id>`

---

All other content (vocabulary definitions, exercise copy, scenario dialogue,
UI text) is original work by the Lekkertaal team and is not covered by the
licences above.
