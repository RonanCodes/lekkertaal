# Research index

Lekkertaal research documents. Each folder covers one research topic tied to a GitHub issue. Docs are bidirectionally linked: each doc's front-matter names its issue + wiki page, and each issue's `## Research output` section links back here. On merge to `main` a doc's `status` flips `draft` → `merged` (canonical). Convention: [`canon/research-tasks.md`](https://github.com/RonanCodes/ronan-skills/blob/main/canon/research-tasks.md) in ronan-skills.
